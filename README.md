## 🎯 Project Overview

This project focuses on understanding password security and learning how password recovery works through authorised cybersecurity lab exercises.

Two practical modules were completed using John the Ripper, Johnny GUI and Networkwalks online tools.

## 🛠️ Tools Used

- John the Ripper (JTR)
- Johnny GUI
- Online PDF Hash Extractor
- Networkwalks Hash Calculator
- Networkwalks Password Cracker

---

## 🔹 Module 1: Password Cracking with John the Ripper

**Objective:** Recover the password of the instructor-provided protected PDF using John the Ripper and Johnny GUI.

### Activities Performed

1. Downloaded and configured John the Ripper.
2. Installed and configured Johnny GUI.
3. Extracted the PDF hash using an online PDF hash extractor.
4. Saved the extracted hash in a text file.
5. Loaded the hash file into Johnny.
6. Started the password recovery process.
7. Verified the recovered password by opening the protected PDF.
